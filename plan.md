# План: smile + камера

Фокус — только на распознавании улыбки и работе с камерой.

## Цели

1. **Сглаживание и трекинг лица**
   - временное сглаживание рамок (не только скора улыбки);
   - отслеживание лица между кадрами, чтобы рамка не «прыгала».

2. **Настройки камеры в UI**
   - выбор индекса/устройства камеры;
   - разрешение и FPS.

3. **Метрики FPS**
   - захват, распознавание, рендеринг;
   - вывод в статусбаре/оверлее.

4. **Качество детекции улыбки**
   - проверка порогов `OPEN`/`SPREAD`/`LIFT` на более широкой выборке;
   - устойчивость к гримасам и оскалу.

5. **Надёжная камера**
   - выбор индекса/устройства камеры;
   - разрешение и FPS.

4. **Метрики FPS**
   - захват, распознавание, рендеринг;
   - вывод в статусбаре/оверлее.

5. **Надёжная камера**
   - переподключение при сбое (сейчас `camera_error` → модальное окно и «мёртвое» приложение);
   - осмысленное сообщение об ошибке + повторная попытка, без перезапуска всего приложения.

## Критерии готовности

- [ ] камера переподключается после сбоя без перезапуска приложения;
- [ ] в UI выбирается камера/разрешение/FPS;
- [ ] рамка лица стабильна (без «прыжков») при неподвижном лице;
- [ ] FPS виден в интерфейсе;
- [ ] скор улыбки не срабатывает на гримасах (тесты в `smokes/`);
- [ ] `just check` зелёный (ruff + mypy + pytest).
