# План: smile + камера

Фокус — только на распознавании улыбки и работе с камерой.

## В работе: фонарик

- детекция фонарика-устройства: ImageNet-классификатор (MobileNet V2, класс `torch`) — работает и для выключенного;
- локализация светящей линзы: порог яркости + связные области → жёлтая рамка;
- статус в статусбаре (`🔦`).

## Цели

1. **Сглаживание и трекинг лица** — ✅ готово
   - временное сглаживание рамок (не только скора улыбки);
   - отслеживание лица между кадрами, чтобы рамка не «прыгала».

2. **Метрики FPS** — ✅ готово
   - захват, распознавание, рендеринг;
   - вывод в статусбаре (cam · face · smile · render).

3. **Качество детекции улыбки** — ✅ готово (основное)
   - проверка порогов `OPEN`/`SPREAD`/`LIFT` на более широкой выборке;
   - устойчивость к гримасам и оскалу;
   - улыбка без зубов (закрытые губы) засчитывается: `SPREAD_MIN` 0.72 → 0.67,
     порог «😊» 0.20 → 0.15.

## Отложено на потом

4. **Настройки камеры в UI**
   - выбор индекса/устройства камеры;
   - разрешение и FPS.

5. **Надёжная камера**
   - переподключение при сбое (сейчас `camera_error` → модальное окно и «мёртвое» приложение);
   - осмысленное сообщение об ошибке + повторная попытка, без перезапуска всего приложения.

## Критерии готовности

- [x] рамка лица стабильна (без «прыжков») при неподвижном лице;
- [x] скор улыбки не срабатывает на гримасах (тесты в `smokes/`);
- [x] `just check` зелёный (ruff + mypy + pytest);
- [x] FPS виден в интерфейсе;
- [ ] камера переподключается после сбоя без перезапуска приложения — позже;
- [ ] в UI выбирается камера/разрешение/FPS — позже.
