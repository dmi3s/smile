# im-nothing

Логотип проекта — кадр из фильма «Люси», после которого уже никто не улыбается.
Сама актриса прекрасная, с прекрасной улыбкой. Выбрал потому, что сильно бьёт
по восприятию: если видел фильм — понимаешь, что это последняя улыбка.

Фонарик — чисто по приколу. Не факт, что работает, просто демонстрация.

Ну и так: всё же нужно улыбнуться, чтобы проверить работу приложения.
